# 数学岛 · 儿童数学练习

两个模块，一套代码，手机 / 平板 / 电脑通用，可装到桌面（PWA）。

| 模块 | 入口 | 说明 |
|---|---|---|
| 数感训练 | `index.html` | 通用数感与计算训练，CPA 三阶段递进 |
| 二年级上 · 同步闯关 | `grade2.html` | **沪教版二上**教材同步，按单元编排的知识点游戏 |

---

## 模块二：二年级上 · 同步闯关（沪教版）

按沪教版二年级上册教材目录编排，**20 个玩法覆盖 6 个单元**：

| 单元 | 玩法 |
|---|---|
| 一 复习与提高 | 方框里填几、巧算 |
| 二 乘法、除法（一） | 乘法的意义、一共多少个、乘法口诀(2·4·8·5·10)、2·4·8 的关系、分一分与除法、用口诀求商、倍/几倍、被除数为 0 |
| 三 统计 | 条形统计图（读图回答最多 / 最少 / 合计） |
| 四 乘法、除法 | 乘法口诀(7·3·6·9)、7·3·6·9 的除法、有余数的除法、分拆为乘与加 |
| 五 几何小实践 | 角与直角（SVG 绘图）、正方体与长方体 |
| 六 整理与提高 | 5个3加3个3等于几个3、乘与除、点图与数 |

**题目全部算法生成**，不做题库抄录；每题自带具象图形辅助理解（分组实物、盘子、条形图、SVG 角）。

家长报告页会按知识点列出掌握率（低于 60% 标 ❗），方便定位薄弱环节。

### 自测
```bash
node test_modes.js      # 20 个模式 × 300 次随机采样，校验每题必含正确答案、选项无重复
```

### 教材版本说明
本模块按**沪教版（上海）**目录编排。沪教版二上与人教版差异很大：

- 沪教版二上 **有除法**（分一分与除法、有余数的除法）、**有统计图**、**有倍的概念**
- 人教版二上是长度单位、100 以内加减、角的认识、表内乘法、观察物体、认识时间

要换成人教版，只需替换 `grade2.js` 里 `MODES` 数组各模式的 `gen()`（框架与渲染不用动）。

# 数学岛 · 数感训练

给自家孩子用的数学启蒙网页版。**一套代码，手机 / 平板 / 电脑通用**，可像原生 App 一样安装到桌面。

> 做它的原因：市面上的数感训练 App（如数感星球）年卡 300+ 元，且内容止于四年级、虚拟商品不支持退款。这个自用版零成本、无广告、可无限扩展难度。

## 玩法设计

依据**新加坡 CPA 教学法**（Concrete 具象 → Pictorial 形象 → Abstract 抽象），一轮 10 题自动分三段递进：

| 阶段 | 题号 | 呈现方式 | 训练目标 |
|---|---|---|---|
| ① 数一数 | 1–3 | 实物图标（🍎🎈），减法把拿走的划掉 | 建立数量直觉 |
| ② 看图想一想 | 4–6 | 点阵图 + 算式填空 | 图形与符号的对应 |
| ③ 直接算 | 7–10 | 纯数字算式 | 抽象运算 |

**三档难度**：10 以内加法 → 20 以内加减 → 100 以内加减（大数自动切换成 🟦=10 / 🟨=1 的十进制块，保持「具象」）。

**激励设计**：答对得星、连对 3 题弹连击提示、结算按得分给评价。音效由 Web Audio 实时合成，零素材文件。

## 技术栈

**零依赖、零构建**——原生 HTML/CSS/JS，不用框架、不用打包器。

- 响应式：CSS 媒体查询 + 移动优先，`clamp()` 自适应字号
- 触控/鼠标统一：单一 click 事件模型
- 离线可用：Service Worker（**network-first** 策略，改代码刷新即时生效）
- 进度存储：localStorage（含每日记录与分知识点统计）
- 电脑端额外支持键盘 1–4 选项、Enter 继续

## 文件结构

```
index.html      数感训练首页
app.js          数感训练逻辑（题库生成 / CPA 渲染 / 音效 / 存储）
grade2.html     二年级上同步闯关首页
grade2.css      同步闯关追加样式
grade2.js       同步闯关 20 个知识点玩法
styles.css      共用皮肤与响应式
test_modes.js   题目生成器自测
manifest.json   PWA 清单（可安装到主屏）
sw.js           Service Worker（离线）
icon.svg        图标
```

## 本地运行

```bash
python -m http.server 8899
# 打开 http://localhost:8899
```

## 安装到手机 / 平板（当原生 App 用）

1. 用手机浏览器打开部署地址
2. **iOS Safari**：分享 → 添加到主屏幕
3. **Android Chrome**：菜单 → 添加到主屏幕 / 安装应用

装完就有独立图标、全屏无地址栏、断网也能玩。

## 扩展方式

数感训练改 `app.js` 的 `LEVELS`；同步闯关改 `grade2.js` 的 `MODES`。

```js
// 数感训练：加一档难度
{ id: 4, emoji: '✖️', name: '乘法口诀', desc: '2~9 的乘法',
  gen() { const a = ri(2,9), b = ri(2,9); return { a, b, op: '×', ans: a*b }; } }
```

```js
// 同步闯关：加一个知识点玩法
{ id: 'clock', unit: '七 认识时间', icon: '🕐', name: '认钟表', desc: '几时几分',
  gen() { /* 返回 { prompt: HTML, options: [...], ans: '...' } */ } }
```

注意：数感训练的 `renderConcrete / renderPictorial / renderAbstract` 需同步支持新的 `op`（目前只处理 `+` 和 `-`）。
